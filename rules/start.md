# Start

- **Repo working memory.**
  - Working memory lives in one file in the repo, which every agent tool reads.
  - Read it at the start of every session.
  - Update it when the owner gives guidance or confirms an approach.
  - Commit it with the work.
  - Write one fact per bullet, with its reason.
  - Keep project memory there, and leave an agent tool's built-in memory unused for the project.
- **Session status.**
  - Give a status overview at the start and end of every session.
  - At the start: what landed since the last session, and the open bugs.
  - At the end: what this session did, and what it left open.
  - Both list leftovers: worktrees, branches, and test devices or processes still running.
- **Own worktree.**
  - Every session works in its own worktree.
  - Prepare it before working, so checks and builds run in it.
- **See what landed.**
  - Before launching agents, check what landed on the working branch.
  - That includes work from other people and other AI tools.
  - Agents build on that work instead of redoing it.
