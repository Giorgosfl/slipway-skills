# Ship: Store

Rules from ship.md that apply only to apps sold through an app store.

- **Store listing in the repo.**
  - The store listing lives in the repo: text, screenshots and store answers.
  - Regenerate it each release.
  - Screenshots use sample content, never the owner's own files.
  - Once the owner asks for a submission, the agent drives it itself.
  - The owner enters only what only they may: passwords, codes and legal answers.
