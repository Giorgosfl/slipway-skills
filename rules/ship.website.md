# Ship: Website

Rules from ship.md that apply only to products with a website.

- **Website matches the app.**
  - A change that alters what the website claims updates the website in the same change.
  - The live website describes only what the released app does.
  - Features not released yet show only as "coming soon".
  - The privacy policy is updated before any feature that changes data handling ships.
  - Check it: read the website against the release notes before each release.
